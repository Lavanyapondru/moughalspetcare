# Moughals Pet Kennel - React Website

Professional responsive pet kennel, boarding, grooming, veterinary care and training website built with React + Vite + Bootstrap 5.

## Run

```bash
npm install
npm run dev
```

## Replace your assets

- Replace `public/logo.jpeg` with your final logo.
- Replace `public/gallery/gallery-1.svg` ... `gallery-10.svg` with your 10 gallery images. If you keep the same filenames, no React code changes are required.
- Add grooming photos to `public/grooming/` and update the grooming page if you want to display a dedicated grooming gallery.
- Replace dummy phone, email, address and hours in `Footer.jsx` and `Contact.jsx`.

## Main routes

- `/` Home
- `/about` About
- `/services` Services
- `/services/boarding` Boarding
- `/services/grooming` Grooming
- `/services/veterinary` Veterinary Care
- `/services/training` Training
- `/gallery` Gallery with lightbox
- `/faq` FAQ
- `/contact` Contact

## Design

The color system is based on the gold/brown/cream look of the supplied Moughals logo and reference image. Animations respect `prefers-reduced-motion`.
